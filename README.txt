ATELINGS EDUCATION CONSULTANCY WEBSITE

Files:
- index.html: website page
- styles.css: design and responsive layout
- script.js: mobile menu, year and enquiry email behavior
- assets/atelings-logo.jpg: supplied ATELINGS logo

Preview:
Open index.html in a web browser.

Before publishing:
1. Replace the contact form's blank mailto destination in script.js with the official business email address (window.location.href='mailto:...').
2. Add verified phone, WhatsApp, office address and social links if wanted.
3. Confirm destination countries, services, admissions claims and scholarship information.
4. Upload the folder to a web host.

This is a front-end starter website. It does not yet have a database, admin panel, or server-side enquiry storage.
